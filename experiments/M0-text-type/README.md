## 이번에 바뀐 것 (계획서와 다른 점)

계획서는 축 B 를 `aku` 의 전개 방식 8종으로 쓰기로 했다. **그 결정을 뒤집었다.**

| | 계획서 | 지금 |
|---|---|---|
| 축 B | aku 8종 | **고시가 직접 나열한 9종** |
| 근거 | 지문 443편에 라벨이 붙어 있음 | 2022 개정 고시 원문 p.48 · p.55 |

이유 두 가지.

1. **aku 라벨은 사람이 붙인 게 아니다.** `lineage` 테이블의 `actor` 가
   `fable-5` 다 — AI 가 붙였다. 정답지로 쓸 수 없다.
2. **고시가 이미 축을 정해 두었다.** 원문에 이렇게 적혀 있다.

   > 서사, 분류, 인과, 정의, 상세화, 예시, 비교, 대조, 문제와 해결 등 다양한
   > 말이나 글의 **전개 방식** 및 문단 구성의 구조에 대한 이해를 바탕으로…

   게다가 이 축을 파악하는 것 자체가 성취기준이다 —
   `[10공영1-01-06] 말이나 글의 전개 방식이나 구조를 파악한다.` 외 5건.
   **활동을 축 B 에 매달면 활동이 자동으로 성취기준에 붙는다.**

축 A 도 마찬가지로 고시가 정해 두었다. 낱개 유형이 아니라 **목적 4범주**로 묶고
학교급별 예시를 든다. `data/text-types.json` 에 쪽수와 함께 옮겨 두었다.

`aku` 8종은 정본에서 물러나 교차 검증용으로만 쓴다.

## 파일

```
data/text-types.json        ★정본★ 축 A 4범주 + 축 B 9종, 고시 쪽수 인용
data/gold-set-hidden.json   aku 의 AI 라벨 (채점 때 비교용, 정답 아님)
data/gold-labels.json       ← 교사가 붙인 정답지. 아직 없음. 이것이 M0 의 핵심 산출물
scripts/build_gold_set.py   aku 기출에서 30편 층화 추출 (seed 20260912, 재현 가능)
scripts/signals.py          AI 없는 판정기 — 표면 신호만
scripts/judge.py            Gemini 판정기 — 고시 목록 밖 답과 없는 근거를 걸러낸다
scripts/score.py            채점. 정답지 없으면 판정기끼리 일치만 보여 준다
out/labeling-sheet.html     교사용 채점표. 그냥 더블클릭해서 연다
out/pred-signals.json       신호 판정 결과
out/pred-ai.json            AI 판정 결과
```

지문 원문(`data/gold-set.json`, `out/gold-set.js`)은 **저장소에 넣지 않는다.**
계획서 §9 의 저작권 방침 그대로다. seed 가 고정되어 있으므로 언제든 다시 만들 수 있다.

```bash
python scripts/build_gold_set.py      # aku.db 에서 같은 30편을 다시 뽑는다
```

## 순서

```bash
# 1. 지문 30편 뽑기 (이미 돌림)
python scripts/build_gold_set.py

# 2. 교사가 라벨 붙이기  ← 사람만 할 수 있는 단계
#    out/labeling-sheet.html 을 열어 30편에 목적·전개 방식을 고른다.
#    다 하면 '정답지 내려받기' → gold-labels.json 을 data/ 로 옮긴다.

# 3. 판정기 돌리기 (이미 돌림 — 2번보다 먼저 돌려도 정답지를 보지 않는다)
python scripts/signals.py
python scripts/judge.py

# 4. 채점
python scripts/score.py
```

**2번을 하기 전에 `out/pred-ai.json` 을 열어 보지 않는다.**
AI 판정을 먼저 보면 정답지가 그쪽으로 끌려간다.
`English_learning_games` 에서 얻은 교훈 — 실패할 수 없는 검사는 검사가 아니다.

## 지금까지 나온 수치 (정답지 없음 — K1 결과 아님)

판정기 3개가 서로 얼마나 같은 답을 내는지만 본 것이다. 셋 다 같이 틀릴 수 있다.

| 비교 | 일치 |
|---|---|
| 목적 · 신호 ↔ AI | 11/23 |
| 전개 방식 · 신호 ↔ AI | 7/25 |
| 전개 방식 · aku ↔ AI | 7/12 (옮길 수 있는 12편만) |

**aku 8종 중 고시 9종으로 옮길 수 없는 지문이 30편 중 18편이다.**
두 축은 같은 종류의 축이 아니다 — aku 는 장르(논증문·실용문)와 전개 방식(서사·예시)을
한 줄에 섞어 놓았다. 이것이 계획서의 축 B 를 갈아엎은 세 번째 이유다.

AI 판정기 품질 (30편):

| | |
|---|---|
| JSON 파싱 실패 | 0 |
| 고시 목록 밖의 답 | 0 |
| 지문에 없는 근거를 지어냄 | 1 / 107 |
| 스스로 "되물음" 표시 | 12 / 30 |
| 신호 판정기가 확신 | 7 / 30 |

AI 가 30편 중 12편에서 스스로 애매하다고 말한 것은 나쁜 신호가 아니다.
계획서 §4 의 "확신이 낮으면 교사에게 되묻는다" 설계가 실제로 작동할 여지가 있다는 뜻이다.
정답지가 나오면 `score.py` 가 **1·2순위 안에 들었는지**도 함께 재므로,
되물음 설계가 정확도를 얼마나 끌어올리는지 수치로 나온다.
